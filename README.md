# Connect-4
Simple Connect-4 game made in Python. Playable in terminal and includes 2 game modes: 1.Player vs Player / 2.Player vs CPU

Written and tested for Python 3.x (no external dependencies required).

* To run:  
`python3 Connect-4.py`

* if `python3` is not in your PATH, use:  
`python Connect-4.py`


* Note on gameplay: board placement requires both row (1–6) and column (1–7) separated by a space (e.g., `6 1` for bottom-left).


* if you encounter this error during player input: "Invalid input. Please enter row and column as numbers."

* You entered a single number instead of two. Ensure you enter both row and column separated by a space (e.g., `6 4`).
